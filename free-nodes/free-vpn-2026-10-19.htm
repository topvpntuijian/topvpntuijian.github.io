第三部分：Clash BT 的常用配置

3.1 Proxy Nodes：配置本地节点和远程节点

Proxy Nodes 是 Clash BT 配置的核心部分，用于配置本地节点和远程节点。在配置文件中，您需要添加代理节点的信息，包括节点名称、类型、服务器地址、端口、密码、加密方式等。

对于 Shadowsocks 节点，您需要配置以下信息：

yaml proxies: - name: "SS Node" type: ss server: server.address.com port: 8388 cipher: aes-256-gcm password: "your_password"

对于 Vmess 节点，您需要配置以下信息：

yaml proxies: - name: "Vmess Node" type: vmess server: server.address.com port: 443 uuid: "your_uuid" alterId: 64 cipher: auto

3.2 Rule Settings：配置和选择哪个请求走代理，哪个请求直连

Rule Settings 是 Clash BT 的另一个重要配置部分，用于配置和选择哪个请求走代理，哪个请求直连。通过合理配置规则，您可以实现精细化的流量控制，提高网络效率。

Clash BT 支持多种规则类型，包括：

  • DOMAIN-SUFFIX：按域名后缀匹配
  • DOMAIN-KEYWORD：按域名关键词匹配
  • GEOIP：按地理位置匹配
  • IP-CIDR：按 IP 地址段匹配
  • MATCH：匹配所有请求

例如，以下规则配置将所有 Google 相关的请求走代理，国内网站直连：

yaml rules: - DOMAIN-SUFFIX,google.com,Proxy - DOMAIN-SUFFIX,googleapis.com,Proxy - GEOIP,CN,DIRECT - MATCH,Proxy

3.3 DNS Settings：配置 DNS 助力访问速度提升

DNS Settings 是 Clash BT 的另一个重要配置部分，用于配置 DNS 助力访问速度提升。通过合理配置 DNS，您可以加快域名解析速度，提高网络访问效率。

Clash BT 支持多种 DNS 配置，包括：

  • nameserver：主 DNS 服务器
  • fallback：备用 DNS 服务器
  • enhanced-mode：增强模式，如 fake-ip

例如，以下 DNS 配置将使用 Cloudflare 和 Google 的 DNS 服务器：

yaml dns: enable: true nameserver: - 1.1.1.1 - 8.8.8.8 fallback: - 114.114.114.114 enhanced-mode: fake-ip

yaml rule-providers: reject: type: http behavior: domain url: "https://raw.githubusercontent.com/Loyalsoldier/clash-rules/release/reject.txt" path: ./ruleset/reject.yaml interval: 86400

TLS+WebSocket 可伪装成正常 HTTPS 流量，增强抗封锁能力和隐蔽性。结合域名伪装和策略组使用，可在高封锁网络环境下保持安全、稳定和高速的网络访问体验。

VMess 配置 TLS+WebSocket 有哪些性能优势？
TLS+WebSocket 可伪装 HTTPS 流量，增强抗封锁能力，同时降低被封检测风险。结合策略组和节点延迟检测，可保证访问速度和连接稳定性，适合视频和游戏场景。

SSR 的协议插件与加密方式如何搭配使用？
协议插件可增强抗封锁能力，加密方式确保数据安全。合理搭配可模拟正常流量特征，同时保障传输安全，有助于在封锁严格环境下维持节点可用性和稳定连接。
